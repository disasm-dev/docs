Ticketmaster runs a reCAPTCHA Enterprise check when a page loads and sets the `tmpt` cookie when it passes. Sign-in and
other protected actions expect a session that has `tmpt`.

We build the reCAPTCHA reload request. You make every request to Ticketmaster and Google yourself, from one session.

Base URL: `https://tmpt.antibotapi.com`

## Before you start

- **User agent:** Chrome 145–155 on Windows, the same string on every request.
- **One session:** the same proxy, cookie jar and `Accept-Language` from the homepage to `tmpt`.
- **A Chrome-like client:** see [Match a real browser](/start/fingerprinting/).

<Steps>

1. Get the reCAPTCHA version from us (`GET /config`).
2. Open Ticketmaster's homepage.
3. Fetch the reCAPTCHA anchor page from Google.
4. Wait at least 200 ms, then get the reload request from us (`POST /tmpt`).
5. Post the reload request to Google and read the token.
6. Send the token to Ticketmaster and store `tmpt`.

</Steps>

`version` is the reCAPTCHA release to fetch the anchor with. It changes when Google ships a release, so read it for each
session. This call is free.

## 2. Open the homepage

1. GET `https://www.ticketmaster.com/` as a page navigation.
2. GET `https://www.ticketmaster.com/eps-mgr` as the page's script request, with `referer: https://www.ticketmaster.com/`.
3. Keep every cookie both responses set. You need `SID`, `BID` and `eps_sid` in step 6.
4. If the homepage answers `403`, Ticketmaster has blocked your proxy. Switch proxy and start again.

## 3. Fetch the anchor page

GET `https://www.google.com/recaptcha/enterprise/anchor` as the page's reCAPTCHA iframe would, with these query
parameters in this order:

| Parameter | Value |
| --- | --- |
| `ar` | `1` |
| `k` | `6LcvL3UrAAAAAO_9u8Seiuf-I6F_tP_jSS-zndXV`, Ticketmaster's site key |
| `co` | `aHR0cHM6Ly93d3cudGlja2V0bWFzdGVyLmNvbTo0NDM.`, the page's origin `https://www.ticketmaster.com:443` in Base64, with `.` for the `=` padding |
| `hl` | `en` |
| `v` | The `version` from step 1 |
| `size` | `invisible` |
| `anchor-ms` | `20000` |
| `execute-ms` | `30000` |
| `ovv` | `CADq00gF` |
| `cb` | A fresh random string for each fetch (see below) |

Put together, with `VERSION` and `CB` filled in:

```
https://www.google.com/recaptcha/enterprise/anchor?ar=1&k=6LcvL3UrAAAAAO_9u8Seiuf-I6F_tP_jSS-zndXV&co=aHR0cHM6Ly93d3cudGlja2V0bWFzdGVyLmNvbTo0NDM.&hl=en&v=VERSION&size=invisible&anchor-ms=20000&execute-ms=30000&ovv=CADq00gF&cb=CB
```

`cb` is two random numbers written in base 36, the second mixed with the current time:

```python
import random
import time

DIGITS = "0123456789abcdefghijklmnopqrstuvwxyz"


def _int32(n: int) -> int:
    n &= 0xFFFFFFFF
    return n - (1 << 32) if n >= (1 << 31) else n


def _base36(n: int) -> str:
    out = ""
    while True:
        n, digit = divmod(n, 36)
        out = DIGITS[digit] + out
        if n == 0:
            return out


def make_cb() -> str:
    first = random.randrange(2147483648)
    second = abs(_int32(random.randrange(2147483648) ^ _int32(int(time.time() * 1000))))
    return _base36(first) + _base36(second)
```

## 4. Get the reload request from us

Wait at least 200 ms after the anchor arrived: a browser needs that long to run reCAPTCHA, and earlier calls are refused
with a `400`. Then:

```js
// anchorHtml and anchorFetched come from step 3. Returns the reload request body as bytes.
async function getReload(apiKey, userAgent, cookies, anchorHtml, anchorFetched) {
  const wait = anchorFetched + 200 - Date.now();
  if (wait > 0) await new Promise((resolve) => setTimeout(resolve, wait));
  const res = await fetch('https://tmpt.antibotapi.com/tmpt', {
    method: 'POST',
    headers: { 'x-api-key': apiKey, 'Content-Type': 'application/json' },
    body: JSON.stringify({ user_agent: userAgent, cookies, anchor_html: anchorHtml, anchor_fetched: anchorFetched }),
  });
  if (!res.ok) throw new Error(`tmpt: ${res.status} ${await res.text()}`);
  return Buffer.from((await res.json()).reload, 'base64'); // binary protobuf
}
```

```go
	}
```

| Field | What to send |
| --- | --- |
| `user_agent` | Your session's `User-Agent`. |
| `cookies` | Your `www.ticketmaster.com` cookies that are not `HttpOnly`, as `name=value` strings. Leave out `tmpt`. An empty array is fine. |

`reload` is the request body as Base64. Each `200` is billed.

<Aside type="caution">
Decode `reload` before you send it to Google's `/reload`. It is a binary protobuf message: post the decoded bytes as they
are, with `content-type: application/x-protobuffer`. Sending the Base64 text, or the bytes converted to a string, gets no
token.
</Aside>

```js
// The token from Google's /reload response.
function parseToken(text) {
  if (!text.startsWith(")]}'")) throw new Error('not a reload response');
  const [kind, token] = JSON.parse(text.slice(text.indexOf('\n') + 1));
  if (kind !== 'rresp' || typeof token !== 'string') throw new Error('no token');
  return token;
}
```

</TabItem>
<TabItem label="Python">

```python
import json


def parse_token(text: str) -> str:
    """The token from Google's /reload response."""
    if not text.startswith(")]}'"):
        raise ValueError("not a reload response")
    reply = json.loads(text.split("\n", 1)[1])
    if reply[0] != "rresp" or not isinstance(reply[1], str):
        raise ValueError("no token")
    return reply[1]
```

<TabItem label="Go">

```go
import (
	"encoding/json"
	"errors"
	"strings"
)

// ParseToken returns the token from Google's /reload response.
func ParseToken(body []byte) (string, error) {
	text := string(body)
	if !strings.HasPrefix(text, ")]}'") {
		return "", errors.New("not a reload response")
	}
	var reply []json.RawMessage
	if err := json.Unmarshal([]byte(text[strings.IndexByte(text, '\n')+1:]), &reply); err != nil {
		return "", err
	}
	var kind, token string
	if len(reply) < 2 || json.Unmarshal(reply[0], &kind) != nil || kind != "rresp" || json.Unmarshal(reply[1], &token) != nil {
		return "", errors.New("no token")
	}
	return token, nil
}
```

## Steps 4–6 in code

These use each language's standard HTTP client to keep them short. Send steps 5 and 6 through your Chrome-like client
(see [Match a real browser](/start/fingerprinting/)), with the headers shown above, in the same session as steps 2 and 3.
They use `parseToken` from step 5.

<Tabs syncKey="lang">
<TabItem label="JavaScript">

```js
const SITE_KEY = '6LcvL3UrAAAAAO_9u8Seiuf-I6F_tP_jSS-zndXV';

// anchorUrl, anchorHtml and anchorFetched come from step 3. cookies are your non-HttpOnly
// www.ticketmaster.com cookies as name=value strings; cookieHeader is the whole cookie header
// for www.ticketmaster.com (SID, BID, eps_sid and the rest). Returns the tmpt Set-Cookie line.
async function getTmpt({ apiKey, userAgent, anchorUrl, anchorHtml, anchorFetched, cookies, cookieHeader }) {
  // 4. Wait until 200 ms after the anchor arrived, then get the reload request.
  const wait = anchorFetched + 200 - Date.now();
  if (wait > 0) await new Promise((resolve) => setTimeout(resolve, wait));
  const made = await fetch('https://tmpt.antibotapi.com/tmpt', {
    method: 'POST',
    headers: { 'x-api-key': apiKey, 'Content-Type': 'application/json' },
    body: JSON.stringify({ user_agent: userAgent, cookies, anchor_html: anchorHtml, anchor_fetched: anchorFetched }),
  });
  if (!made.ok) throw new Error(`tmpt: ${made.status} ${await made.text()}`);
  const reload = Buffer.from((await made.json()).reload, 'base64'); // binary protobuf

  // 5. Post the bytes to Google and read the token.
  const google = await fetch(`https://www.google.com/recaptcha/enterprise/reload?k=${SITE_KEY}`, {
    method: 'POST',
    headers: { 'user-agent': userAgent, 'content-type': 'application/x-protobuffer', referer: anchorUrl },
    body: reload,
  });
  const token = parseToken(await google.text());

  // 6. Hand the token to Ticketmaster. The response sets tmpt.
  const view = await fetch('https://www.ticketmaster.com/epsf/gec/v3/pageView', {
    method: 'POST',
    headers: { 'user-agent': userAgent, 'content-type': 'application/json', referer: 'https://www.ticketmaster.com/', cookie: cookieHeader },
    body: JSON.stringify({ hostname: 'www.ticketmaster.com', key: SITE_KEY, token }),
  });
  const tmpt = view.headers.getSetCookie().find((cookie) => cookie.startsWith('tmpt='));
  if (!tmpt) throw new Error(`pageView ${view.status}: no tmpt`);
  return tmpt;
}
```

```go
	"encoding/base64"
	"encoding/json"

	"io"

const siteKey = "6LcvL3UrAAAAAO_9u8Seiuf-I6F_tP_jSS-zndXV"

// GetTmpt does steps 4-6. client is your Ticketmaster session, with a cookie jar holding the
// cookies from step 2. anchorURL, anchorHTML and anchorFetched come from step 3; cookies are
// your non-HttpOnly www.ticketmaster.com cookies as name=value strings.
func GetTmpt(client *http.Client, apiKey, userAgent, anchorURL, anchorHTML string, anchorFetched int64, cookies []string) (*http.Cookie, error) {
	// 4. Wait until 200 ms after the anchor arrived, then get the reload request.
	time.Sleep(time.Until(time.UnixMilli(anchorFetched + 200)))
	body, _ := json.Marshal(map[string]any{"user_agent": userAgent, "cookies": cookies, "anchor_html": anchorHTML, "anchor_fetched": anchorFetched})
	req, _ := http.NewRequest("POST", "https://tmpt.antibotapi.com/tmpt", bytes.NewReader(body))
	req.Header.Set("x-api-key", apiKey)
	req.Header.Set("Content-Type", "application/json")
	resp, err := http.DefaultClient.Do(req)
	if err != nil {
		return nil, err
	}
	var made struct {
		Reload string `json:"reload"`
	}
	err = json.NewDecoder(resp.Body).Decode(&made)
	resp.Body.Close()
	if resp.StatusCode != http.StatusOK || err != nil {
		return nil, fmt.Errorf("tmpt: %d %v", resp.StatusCode, err)
	}
	reload, err := base64.StdEncoding.DecodeString(made.Reload) // binary protobuf
	if err != nil {
		return nil, err
	}

	// 5. Post the bytes to Google and read the token.
	req, _ = http.NewRequest("POST", "https://www.google.com/recaptcha/enterprise/reload?k="+siteKey, bytes.NewReader(reload))
	req.Header.Set("user-agent", userAgent)
	req.Header.Set("content-type", "application/x-protobuffer")
	req.Header.Set("referer", anchorURL)
	resp, err = client.Do(req)
	if err != nil {
		return nil, err
	}
	text, _ := io.ReadAll(resp.Body)
	resp.Body.Close()
	token, err := ParseToken(text)
	if err != nil {
		return nil, err
	}

	// 6. Hand the token to Ticketmaster. The response sets tmpt.
	view, _ := json.Marshal(map[string]string{"hostname": "www.ticketmaster.com", "key": siteKey, "token": token})
	req, _ = http.NewRequest("POST", "https://www.ticketmaster.com/epsf/gec/v3/pageView", bytes.NewReader(view))
	req.Header.Set("user-agent", userAgent)
	req.Header.Set("content-type", "application/json")
	req.Header.Set("referer", "https://www.ticketmaster.com/")
	resp, err = client.Do(req)
	if err != nil {
		return nil, err
	}
	resp.Body.Close()
	for _, cookie := range resp.Cookies() {
		if cookie.Name == "tmpt" {
			return cookie, nil
		}
	}
	return nil, fmt.Errorf("pageView %d: no tmpt", resp.StatusCode)
}
```

## When it fails

| Status | Cause | What to do |
| --- | --- | --- |
| `400` | A field is missing or wrong, the user agent is not Chrome 145–155 on Windows, or the call came less than 200 ms after the anchor arrived. The message says which. | Fix it. If your server's clock is ahead of ours, the gap can come out short. |
| `401` | The API key is missing, wrong or out of balance. | Check the key. |
| `409` | The anchor is from a reCAPTCHA version we do not support yet. | Fetch the anchor with the `version` from `GET /config`. |
| `501` | This anchor asks for something we cannot build yet. Not billed. | Tell us. |
| `503` | Temporarily unavailable. | Retry after a few seconds. |

If Google returns no `rresp` token, or Ticketmaster does not set `tmpt`, check that your session used one proxy and one
user agent throughout, and that your client matches Chrome.

All fields are in the [API reference](/api/tmpt/).
