The Developer API gives you the dashboard's data from code: your profile, balances, API keys and usage.

Base URL: `https://api.disasm.dev`

## Authentication

Send your API key as a Bearer token. This API does not use `x-api-key`.

```bash
curl https://api.disasm.dev/v1/balance -H "Authorization: Bearer YOUR_API_KEY"
```

## Endpoints

| Endpoint | What it returns |
| --- | --- |
| `GET /v1/me` | Your profile, wallet balance and subscriptions. |
| `GET /v1/balance` | Your wallet balance and each key's plan balance. |
| `GET /v1/keys` | Your API keys, with status, balance and usage. |
| `GET /v1/keys/{id}` | One key. |
| `POST /v1/keys/{id}/rotate` | Replaces a key. The old one stops working at once; the new one is returned once only. |
| `GET /v1/usage` | Request counts over `24h`, `7d`, `30d` or `90d`, optionally for one key. |

Schemas and examples are in the [API reference](/api/developer/).

## Rate limits

60 requests a minute. Every response carries:

| Header | Meaning |
| --- | --- |
| `X-RateLimit-Limit` | Requests allowed per minute. |
| `X-RateLimit-Remaining` | Requests left in this minute. |
| `X-RateLimit-Reset` | When the minute resets, as a Unix timestamp. |
| `X-Balance-Remaining` | Plan requests left across all your keys. |
| `X-PAYG-Balance` | Your wallet balance, in pence. |

Past the limit you get a `429`.
